
# 🛒 KiranaConnect

### Smart Digital Platform for Local Kirana Stores

KiranaConnect is a digital platform designed to connect local kirana stores with customers through an easy-to-use online shopping experience. It helps traditional grocery stores establish an online presence, manage products, and serve customers more efficiently.

## 🚀 Features

- **User-Friendly Interface:** Simple and responsive shopping experience.
- **Product Management:** Browse and manage grocery products.
- **Shopping Experience:** Explore products and add items to cart.
- **Order Management:** Simplify the ordering process.
- **Full-Stack Architecture:** Separate frontend and backend applications.
- **Dashboard:** Visualize relevant store and order information.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Dharshhhhh/kiranaconnect.git
```

### 2. Navigate to the Project

```bash
cd kiranaconnect
```

### 3. Setup Backend

```bash
cd backend
npm install
```

Start the backend using the start script defined in its package.json.

### 4. Setup Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

## 💡 Project Objective

The main objective of KiranaConnect is to support local grocery stores in adopting digital technology, improving accessibility for customers, and making everyday grocery shopping more convenient.
